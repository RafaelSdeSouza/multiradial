Citing MultiRadial
==================

Use the repository ``CITATION.cff`` file for software citation metadata. Until
the accompanying paper receives final bibliographic metadata, cite both the
software version and the manuscript title:

*R. S. de Souza, “Radial profiles in multi-centred astronomical structures”.*

The DOI and final journal reference should be added to ``CITATION.cff`` only
after they exist; no placeholder DOI is supplied.
