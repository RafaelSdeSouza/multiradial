# Maintained notebooks

The maintained tutorial sequence is:

1. `01_quickstart.ipynb`
2. `02_understanding_coordinates.ipynb`
3. `03_your_own_image.ipynb`
4. `04_registered_tracers.ipynb`

Each notebook is stored with executed outputs. Colab links will be added only
after an immutable release tag exists, so installation can reference an exact
source revision.

`tutorial.ipynb` and `interactive_explorer.ipynb` are retained as historical
development examples. They are not part of the maintained public tutorial
sequence.
